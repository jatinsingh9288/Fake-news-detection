Fake News Detection Using Machine Learning

A Flask web app that uses a TF-IDF vectorizer and a Passive Aggressive classifier to label news article text as FAKE or REAL.

🧠 Start Detecting

⚙️ How It Works

1. Input

You paste the text of a news article on the Prediction page.

2. TF-IDF

The text is converted into TF-IDF features by a saved vectorizer.

3. Classifier

A saved Passive Aggressive classifier predicts the label.

4. Result

The page shows FAKE or REAL. It is a model prediction, not a fact-check.
