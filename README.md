# Fake News Detection
A simple Machine Learning project that predicts whether a news article is **Fake or Real**.
## Tech Used
* Python
* Flask
* Scikit-learn
* Pandas
* HTML/CSS

## Model
* TF-IDF Vectorizer
* Passive Aggressive Classifier
The model achieved **95.11% accuracy** on the test data used during evaluation.

## How It Works
User enters a news article → TF-IDF converts the text into features → ML model predicts **Fake or Real**.

## Project Files
* `app.py` – Flask application
* `Fake News Detection.ipynb` – Model training
* `finalized_model.pkl` – Trained model
* `vectorizer.pkl` – TF-IDF vectorizer
* `templates/` – HTML pages
* `static/` – Static files

## Note
This project is for learning purposes. The prediction is not a real fact-checking system.
